# Kazuma Minoda

携帯ショップでの接客・販売の経験を活かし、現場の課題を形にできるWebエンジニアを目指しています。
Ruby on Rails を中心に、設計からデプロイ・運用まで、一通り自分の手で行ってきました。

## 💼 ポートフォリオ

### [料金シミュレーター (plan_simulator)](https://plan-simulator.kazkaz9717.com/)
携帯ショップの店頭スタッフ向けに、プラン・割引・機種などを組み合わせて月額料金を計算し、最大3パターンを比較できるツールです。

[デモ](https://plan-simulator.kazkaz9717.com/) / [リポジトリ](https://github.com/kazkaz9717/plan_simulator)




### [出産前後管理アプリ (papa_app)](https://papa-app.kazkaz9717.com/)
夫婦で出産前後の段取り・行政手続き・育休給付金・育児記録等を共有しながら管理できるアプリです。

[デモ](https://papa-app.kazkaz9717.com/) / [リポジトリ](https://github.com/kazkaz9717/papa_app)
